# OpenLive Studio 项目方案

产品采用单画布，所有来源在统一来源列表中管理，并合成到唯一画布。取消多场景管理与场景切换功能。

以下为目标功能规划，不代表当前均已实现。现有多场景代码将分步移除；本次移除不补齐来源添加、采集、合成、配置保存或输出功能。

## MVP 功能

1. **单画布**：唯一画布承载来源合成与预览。
2. **来源管理**：统一列表管理显示器采集、窗口采集、摄像头、图片、文字。
3. **画面合成**：拖动/缩放/层级调整，简单预览。
4. **音频采集**：麦克风 + 系统声音混音，音量调节。
5. **本地录制**：输出 MKV/MP4。
6. **RTMP 推流**：填推流地址和密钥，开始/停止。
7. **编码**：优先 FFmpeg 软件编码，能加 NVENC/QSV 更好。
8. **快捷键**：开始/停止录制。
9. **断线重连/异常恢复**：推流断开重连，MKV 崩溃可修复。
