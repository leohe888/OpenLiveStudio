# 2026-11-02

## 视频源配置类型统一为 Config

- 把 `VideoSourceConfig` 变体里三个分支结构体从 `*Params` 改为 `*Config`：`DisplaySourceConfig`、`CameraSourceConfig`、`ImageSourceConfig`；滤镜侧同步改为 `ColorCorrectionConfig`、`VideoSourceFilterConfig`。
- 配套改名：`VideoSourceFilter::params → config`、`CameraCaptureWorker::m_params → m_config`、`CameraMode::params() → config()`、`VideoSourceManager::setCameraParams/setDisplayParams/setFilterParameters → setCameraConfig/setDisplayConfig/setFilterConfig`、`CameraSourceController::Entry::params → config`，以及测试槽名（`configAndLayout`、`cameraConfigValidation`、`configValidation`、`supportsAllSourceConfigs`）。
- 起因：`3e78655` 把所有 `*Config` 改成 `*Params`，`0416863` 只把联合类型改回 `VideoSourceConfig`，留下 `VideoSourceConfig = variant<...Params>` 的半截状态。
- 验证：`build/qt-ninja-Debug` 全量构建通过，ctest 13/13 通过。

## 运行时状态内置到 VideoSource

- 删除 `VideoSourceManager::m_statuses`（`QHash<QString, VideoSourceStatus>`），改在 `VideoSource` 上加 `VideoSourceRuntime runtime{pixelSize, state, error, actualFrameRateNumerator/Denominator}`；`addSource(const VideoSource&)` 不再接收独立 status 参数，`sourceStatus()` 改为从源实体读取。
- 初始化构造函数与 `addSource` 都用 `runtime.pixelSize` 兜底 `canvasGeometry`，源快照拷贝时携带运行时信息。
- `setCameraActualMode` 在触发几何通知后改用 `sourceRow()` 重新定位，避免通知中重排序导致的悬垂引用；新增测试 `sourceReorderingDuringGeometryNotificationIsSafe`。
- 提交：`ec0c4bb refactor(video): keep runtime state on the source`；ctest `core.videosourcemanager` 通过。

## 源配置/运行时结构体改为封装类

- `DisplaySourceConfig`、`CameraSourceConfig`、`ImageSourceConfig`、`VideoSourceRuntime`、`VideoSource` 从 `struct` 改为 `class`，字段全部私有，统一走 `x()` / `setX()` 访问器；构造函数保留聚合式调用习惯（`VideoSource{id, name, config}` 仍可用）。
- 全仓改为访问器调用：管理器、三个 source controller、aggregator、mainwindow、视频源面板及相关测试。
- 提交：`d2f46d3 refactor(video): encapsulate source config and runtime behind accessors`（按用户要求未跑构建/测试）。
- 注意：`m_sources[row].runtime()` 返回 `const&`，修改需「取值 → 改副本 → setRuntime 写回」，不要再对成员直接取引用赋值。

## 滤镜与几何封装、构造默认参数拆分

- `ColorCorrectionConfig`、`VideoSourceFilter` 改为 class + 访问器（并补 `operator!=`）；`VideoSourceFilter` 提供 `(id)` 与 `(id, enabled, config)` 两个构造。
- 值类型构造拆分为「少参数重载 + 完整重载」：`DisplaySourceConfig(displayId)` / `(displayId, captureCursor)`、`CameraSourceConfig(deviceId)` / `(deviceId, resolution, num, den)`、`VideoSourceRuntime(pixelSize, state, error)` / `(+帧率)`、`VideoSource(id, name)` / `(+config)` / 完整重载、`VideoSourceCanvasGeometry(center, size)` / `(+rotation)`。目的是去掉默认实参，避免聚合式调用时静默丢字段。
- 提交：`6e3ee24 refactor(video): encapsulate filters and drop default ctor arguments`（按要求未跑构建/测试）。
- 待验证：这批改动尚未编译，后续首次构建需注意调用点是否都显式传参。
